# templates

The scaffold a romlift project is created with: `Makefile`, `setup.sh`, `include/**`, the project's
`AGENTS.md`, `build.yml`, `gitignore`, `README.md`, the per-compiler makefile fragments and the pinned
agbcc reference, listed in `MANIFEST.json`. They ship inside the npm package and land in phase 4
(architecture §6.3). This `index.md` describes the directory and is not itself a template.
